DASTURXON — Admin + Mijoz tizimi

Yangilanish:
- Admin Stol qo'shish va Stolni chiqarish (o'chirish) funksiyasiga ega.
- Stol nomini masalan "13" yoki "Stol 13" ko'rinishida qo'shish mumkin.
- Stolni chiqarish faqat stol bo'sh bo'lsa ishlaydi; band/aktiv buyurtmali stolni avval bo'shatish kerak.
- Adminning stol ro'yxati localStorage orqali saqlanadi.
- Mijoz sahifasidagi bron va buyurtma stol tanlovlari admin qo'shgan/chiqargan stollarga avtomatik moslashadi.
- Bron qilingan stol admin tasdiqlagandan keyin band hisoblanadi.
- Buyurtma qabul qilingandan keyin Stolni bo'shatish tugmasi chiqadi.

Fayllar:
- dasturxon-admin.html — Admin panel
- dasturxon-demo.html — Mijoz sahifasi
- main.js — Admin logikasi
- stayle.css — Admin dizayni

Ishga tushirish:
1. ZIP ni oching.
2. dasturxon-admin.html yoki Live Server orqali oching.
3. Admin: admin / admin123
4. Mijoz: mijoz / mijoz123

Eslatma: localStorage ishlatilgani sababli admin va mijoz ma'lumotlari bir xil brauzer/originda sinxronlanadi. Haqiqiy turli qurilmalarda ishlashi uchun Firebase/Supabase/backend kerak.
